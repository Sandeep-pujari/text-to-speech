# Text-to-Speech

**Text-to-Speech** is a web project that converts typed text into spoken audio using JavaScript and the Web Speech API. Users can also select different voices to hear the output in various accents.

## Features
- Convert any text input to speech
- Choose from multiple voices
- Adjustable pitch and rate (optional)
- Works directly in the browser

## Tech Stack
- HTML
- CSS
- JavaScript (Web Speech API)

## How to Use
1. Open `index.html` in a web browser
2. Type your text into the textarea
3. Select a voice from the dropdown
4. Click the "Speak" button to hear the text
